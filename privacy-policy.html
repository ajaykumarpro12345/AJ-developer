1. Information We Collect

When you submit a project inquiry on AJ Developers, we collect only the information you voluntarily provide:

  • Contact Details: Your name and email address.
  • Project Preferences: Selected service package (Website or Website + APK), website type, APK type (if applicable), product description, and optional reference URL.
  • Basic Analytics: Aggregated, privacy-respecting usage statistics via Firebase Analytics to improve website performance.

2. How We Use Your Information

3. Data Storage & Security

Inquiry submissions are securely stored in Google Cloud Firestore (Firebase) with strict security rules that block unauthorized public read/write access, and transmitted over HTTPS encryption.
